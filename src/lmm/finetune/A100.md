# A100 large-data LoRA training — ready-made pipeline

**Goal:** the only remaining bottleneck is Qwen-3B **capacity** (extraction,
language control, recall consistency). The architecture has settled; this step
strengthens the engine. Not on the M5 but **on an A100 with large data** —
when you get an A100, run the steps below in order.

## What we teach (three behaviors, all condition-5 clean)
1. **EXTRACTION** (the real bottleneck) — sentence → triple + WRITE/ASK
   distinction. Data comes from the STRUCTURAL fields of `tanim-temiz.jsonl`
   (concept/relation/target/sentence), **~112k aligned examples**, without
   asking Qwen. This fixes mistaking "what is X" for WRITE in chat and missing
   Turkish possessive sentences.
2. **GROUNDED ANSWER + REFUSAL** — "speak only from the given fact, refuse
   otherwise". Self-distillation (language-filtered), scaled up.
3. **IDENTITY** — multilingual, correctness-harvested (closes surface drift).

## 1) Setup (A100 box)
```bash
pip install torch transformers peft datasets accelerate
# models/qwen-3b/ and data/train/*.jsonl must be on the box (move repo + data)
```

## 2) Produce data
```bash
# a) EXTRACTION — all of it (~112k, fast, no Qwen)
python3 -m lmm.finetune.make_extract_data --out data/train/extract.jsonl

# b) GROUNDING + refusal + identity (self-distillation — Qwen is fast on A100;
#    give a large --limit, e.g. 8000; language filter + identity harvest built in)
python3 -m lmm.finetune.make_data --limit 8000 --out data/train/lora.jsonl

# c) COMBINE (extraction-heavy; everything in one file)
cat data/train/extract.jsonl data/train/lora.jsonl > data/train/all.jsonl
wc -l data/train/all.jsonl     # expect ~120k+ lines
```

## 3) Train — OVERNIGHT MAX QUALITY (A100, 8-10 hour target)
```bash
python3 -m lmm.finetune.train \
  --data data/train/all.jsonl --out models/lmm/lora \
  --epochs 3 --rank 64 --batch 8 --grad-accum 4 --max-len 1024 --lr 1e-4 --mlp
```
Why these settings are best:
- **`--mlp`**: targets attention + MLP (gate/up/down) → **~2x capacity**. The
  main quality lever of the long overnight run.
- **rank 64** (16 on M5, 32 on a light A100): high capacity, an A100 handles it.
- **batch 8 × grad-accum 4 = effective 32**; **max-len 1024** (full sentences
  fit). Comfortable on a 40GB Colab A100 with gradient checkpointing. If
  memory is free, try batch 16.
- **bf16 + cosine LR + 3% warmup** automatic → stable, high-quality convergence.
- ~130k examples, 3 epochs: roughly **4-7 hours** of training on an A100
  (+ ~2-3h data production). Fits within the night; finishing early is fine —
  quality matters more than filling the time.

**If Colab drops, resume:**
```bash
python3 -m lmm.finetune.train --data data/train/all.jsonl --out models/lmm/lora \
  --epochs 3 --rank 64 --batch 8 --grad-accum 4 --max-len 1024 --lr 1e-4 --mlp \
  --resume models/lmm/lora/checkpoint-XXXX   # latest checkpoint folder
```

**Scale grounding up too (the night has time):** in step 2b give
`--limit 12000` (richer grounded/refusal; Qwen is fast on an A100, ~2-3 hours
of self-distillation).

## 4) Validate (after training, on the box)
```bash
python3 - <<'PY'
import tempfile
from lmm.session import Session
S=Session(tempfile.mktemp(suffix=".lmm"))
for m in ["Paris Fransa'nın başkentidir","paris nedir","seni kim yaptı",
          "biliyor musun balina bir memelidir","balina nedir"]:
    print(m,"->",S.respond(m))
PY
```
Expected improvement: Turkish possessive sentences are now learned
(extraction), recall is consistent, identity is solid, language leakage
(Chinese/English) reduced.

## 5) Deployment (merge + GGUF — fine-tuned on cheap CPU)
```bash
python3 - <<'PY'
import torch
from transformers import AutoModelForCausalLM
from peft import PeftModel
m=AutoModelForCausalLM.from_pretrained("models/qwen-3b",dtype=torch.float16)
m=PeftModel.from_pretrained(m,"models/lmm/lora").merge_and_unload()
m.save_pretrained("models/qwen-3b-lmm"); print("merged → models/qwen-3b-lmm")
PY
# then convert qwen-3b-lmm to Q4_K_M with the GGUF steps in the repo root → CPU deployment
```

## Important notes
- **condition-3 holds:** this is BEHAVIOR fine-tuning; knowledge still enters
  the graph and grows without retraining.
- **condition-5 holds:** extraction targets come from the structure of real
  data, grounding/identity from Qwen self-distillation — no hand-written
  sentences.
- **v2 lesson:** don't over-produce identity data from a flaky teacher;
  make_data already applies correctness harvesting + the language filter.
  Small but clean > large but noisy (for identity).
- **M5 fallback:** without an A100 the same commands run on the M5 with
  `--rank 16 --batch 1 --grad-accum 16` (slow, hours), but even the extraction
  data alone (just a, without b) improves things noticeably.
