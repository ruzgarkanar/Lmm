# A100 büyük-veri LoRA eğitimi — hazır boru hattı

**Amaç:** kalan tek darboğaz Qwen-3B **kapasitesi** (extraction, dil kontrolü,
recall tutarlılığı). Mimari oturdu; bu adım motoru güçlendirir. M5'te değil, **büyük
veriyle A100'de** — sen A100 bulunca aşağıyı sırayla koş.

## Ne öğretiyoruz (üç davranış, hepsi condition-5 temiz)
1. **EXTRACTION** (asıl darboğaz) — cümle → üçlü + WRITE/ASK ayrımı. Veri
   `tanim-temiz.jsonl`'nin YAPISAL alanlarından (kavram/ilişki/hedef/cümle),
   **~112k hizalı örnek**, Qwen'e sormadan. Sohbette "X nedir"i WRITE sanma ve
   Türkçe iyelik cümlelerini kaçırma sorununu bu çözer.
2. **GROUNDED CEVAP + RET** — "yalnız verilen olgudan konuş, yoksa reddet".
   Self-distillation (dil-filtreli), ölçeklenmiş.
3. **KİMLİK** — çok-dilli, doğruluk-hasatlı (yüzey sapmasını kapatır).

## 1) Kurulum (A100 kutusu)
```bash
pip install torch transformers peft datasets accelerate
# models/qwen-3b/ ve data/train/*.jsonl kutuda olmalı (repo + veriyi taşı)
```

## 2) Veri üret
```bash
# a) EXTRACTION — tümü (~112k, hızlı, Qwen'siz)
python3 -m lmm.finetune.make_extract_data --out data/train/extract.jsonl

# b) GROUNDING + refusal + identity (self-distillation — A100'de Qwen hızlı;
#    büyük --limit ver, ör. 8000; dil-filtresi + kimlik-hasadı içeride)
python3 -m lmm.finetune.make_data --limit 8000 --out data/train/lora.jsonl

# c) BİRLEŞTİR (extraction ağırlıklı; hepsi tek dosya)
cat data/train/extract.jsonl data/train/lora.jsonl > data/train/all.jsonl
wc -l data/train/all.jsonl     # ~120k+ satır beklenir
```

## 3) Eğit — GECE BOYU EN KALİTE (A100, 8-10 saat hedef)
```bash
python3 -m lmm.finetune.train \
  --data data/train/all.jsonl --out models/lmm/lora \
  --epochs 3 --rank 64 --batch 8 --grad-accum 4 --max-len 1024 --lr 1e-4 --mlp
```
Neden bu ayarlar en iyisi:
- **`--mlp`**: attention + MLP (gate/up/down) hedeflenir → **kapasite ~2x**. Uzun
  gece run'ında asıl kalite kaldıracı bu.
- **rank 64** (M5'te 16, hafif A100'de 32): yüksek kapasite, A100 kaldırır.
- **batch 8 × grad-accum 4 = efektif 32**; **max-len 1024** (tam cümleler sığar).
  40GB Colab-A100'de gradient-checkpointing ile rahat. Bellek boşsa batch 16 dene.
- **bf16 + cosine LR + %3 warmup** otomatik → kararlı, kaliteli yakınsama.
- **checkpoint her 500 adım** (`save_total_limit=2`) → Colab düşerse kaybolmaz.
- ~130k örnek, 3 epoch: A100'de kabaca **4-7 saat** eğitim (+ veri üretimi ~2-3s).
  Toplam gecenin içinde biter; erken biterse sorun değil, kalite süreyi doldurmaktan önemli.

**Colab düşerse devam:**
```bash
python3 -m lmm.finetune.train --data data/train/all.jsonl --out models/lmm/lora \
  --epochs 3 --rank 64 --batch 8 --grad-accum 4 --max-len 1024 --lr 1e-4 --mlp \
  --resume models/lmm/lora/checkpoint-XXXX   # son checkpoint klasörü
```

**Grounding'i de büyüt (gece vakti var):** adım 2b'de `--limit 12000` ver (daha
zengin grounded/refusal; A100'de Qwen hızlı, ~2-3 saat self-distillation).

## 4) Doğrula (eğitim sonrası, kutuda)
```bash
python3 - <<'PY'
import tempfile
from lmm.session import Session
S=Session(tempfile.mktemp(suffix=".lmm"))
for m in ["Paris Fransa'nın başkentidir","paris nedir","seni kim yaptı",
          "biliyor musun balina bir memelidir","balina nedir"]:
    print(m,"->",S.respond(m))
PY
```
Beklenen düzelme: Türkçe iyelik cümleleri artık öğreniliyor (extraction), recall
tutarlı, kimlik sağlam, dil sızıntısı (Çince/İng) azalmış.

## 5) Dağıtım (merge + GGUF — ucuz CPU'da ince-ayarlı)
```bash
python3 - <<'PY'
import torch
from transformers import AutoModelForCausalLM
from peft import PeftModel
m=AutoModelForCausalLM.from_pretrained("models/qwen-3b",dtype=torch.float16)
m=PeftModel.from_pretrained(m,"models/lmm/lora").merge_and_unload()
m.save_pretrained("models/qwen-3b-lmm"); print("merged → models/qwen-3b-lmm")
PY
# sonra kök dizindeki GGUF adımlarıyla qwen-3b-lmm'i Q4_K_M'e çevir → CPU dağıtımı
```

## Önemli notlar
- **condition-3 korunur:** bu DAVRANIŞ ince-ayarı; bilgi hâlâ grafa girer, retrain'siz büyür.
- **condition-5 korunur:** extraction hedefleri gerçek verinin yapısından, grounding/kimlik Qwen öz-damıtımından — elle cümle yok.
- **v2 dersi:** kimlik verisini oynak öğretmenden çok üretme; make_data zaten doğruluk-hasatı + dil-filtresi uyguluyor. Küçük ama temiz > büyük ama gürültülü (kimlik için).
- **M5 fallback:** A100 yoksa aynı komutlar M5'te `--rank 16 --batch 1 --grad-accum 16` ile çalışır (yavaş, saatler), ama extraction verisi (b'siz, sadece a) bile belirgin düzeltir.
